Repositorio Seguridad y Alta Disponibilidad
------------------------------------------
Arrancado Lab Bodegas - Baterias - Creada Rama Baterias <-> ./lab.sh parar
<-> Hacia Main -> Practica

Cuatro reglas:

Lanza las órdenes desde la carpeta de la práctica (kit-sad-p2/), la misma de la que lanzas el mando.
Trabaja en la rama main. Compruébalo con git branch --show-current: tiene que decir main. Si dice otra cosa, git switch main. Se corrige lo que hay en main.
El mensaje empieza por el número de la actividad y dice qué has hecho. ✅ A7: NAT de la centralita · ❌ cambios, update, practica. Si la actividad se queda a medias, haz el commit igual y dilo: A2: a medias, falta probarlo.
Un commit por actividad, no uno enorme al final. Si haces más, mejor: guardar de más no quita nada.
